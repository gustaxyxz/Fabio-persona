# Rota

Projeto acadêmico baseado na persona Fábio Alves, motorista de van universitária que enfrenta dificuldades com rotas, combustível e cansaço na rotina noturna.

## Estrutura do repositório

- Site publicado no GitHub Pages: arquivos principais ficam na raiz para não quebrar a hospedagem.
- Sprint 1: materiais da persona em sprint-1.
- Sprint 2: documentação da sprint em sprint-2.
- Projeto final: guia de entrega e ZIP em projeto-final.
- Referências: rubricas e materiais de apoio em referencias.
- Arquivos antigos: testes e versões descartadas em arquivos-antigos.

## Observação importante

Os arquivos da raiz foram mantidos porque o GitHub Pages publica o site diretamente a partir deles. A organização por sprint foi feita sem mover a aplicação principal, para preservar a entrega online.
