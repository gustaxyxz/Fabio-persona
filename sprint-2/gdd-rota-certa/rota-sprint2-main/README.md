# Rota

Sistema web simples para apoiar a organizacao de embarques e a revisao de enderecos em rotas noturnas.

## Funcionalidades principais

- Apresentacao da persona e dos problemas da rotina.
- Estrutura de navegacao clara entre secoes do site.
- Conteudo de mini game conceitual para revisao aluno-endereco.
- Controle de idade para liberar conteudo sensivel.
- Alternancia de tema claro/escuro.
- Mensagem personalizada a partir de campo de texto.

## Arquivos principais

- index.html
- style.css
- script.js
- mini-gdd-rota-certa.md
- mini-gdd-rota-certa.docx
